# MediTrust

Trusted Healthcare Journey & Patient Support Platform

> Right Care. Right Hospital. Right Support.

## About

MediTrust is a patient-centric healthcare navigation and support platform that helps patients find a suitable hospital, understand why it's recommended (Trust Engine + Match Score), connect with verified doctors, and manage the full treatment journey — including stay, travel, home healthcare, and follow-up.

This repository is in early setup. See `docs/` for the Product Requirements Document and related planning notes as they are added.
